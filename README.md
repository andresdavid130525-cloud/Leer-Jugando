# Leer Jugando

Juegos por equipos para aprender lectoescritura musical en quinto grado de primaria. Se usan con un computador y un proyector, y también funcionan en celular.

- **Ritmo en Equipo** (lectura rítmica): disponible.
- **Notas al Vuelo** (lectura melódica): en diseño.
- **Dictado en Equipo** (escritura musical): en diseño.

La página no guarda ni envía datos de los estudiantes: el marcador vive solo en el navegador donde se juega.
